# 口播视频技能（boke-creator）

对着 AI 助手说话，把你的一个观点做成一条 60–90 秒的竖屏视频：**你的声音 + 全屏文字动画 + 逐字对齐的字幕**。不用出镜，不用显卡，不用剪辑软件，声音和稿子都留在你自己的电脑上。

适合：想用短视频表达自己的观点，但不想露脸、不会剪辑的人。

## 你需要准备

- 一台 Windows 10/11 或 Mac 电脑，约 1.5 GB 空闲磁盘。
- [Claude Code](https://claude.com/claude-code) 或 Codex（能读技能、能运行命令的 AI 助手）。
- [Node.js](https://nodejs.org) LTS 版（18 以上）。装完重开终端。
- 一部能录音的手机。

## 安装

1. 把整个 `boke-creator` 文件夹放到助手的技能目录：
   - Claude Code：`~/.claude/skills/boke-creator/`（Windows 是 `C:\Users\你的用户名\.claude\skills\boke-creator\`）
   - Codex：`~/.codex/skills/boke-creator/`
2. 打开助手，说：

   > 用 boke-creator 技能，帮我装好环境。

   它会运行安装脚本，下载约 500 MB 的东西（渲染程序、浏览器、识别模型），全部放在技能文件夹里，不改系统。也可以自己在技能文件夹里运行：

   ```bash
   node tools/setup.mjs
   ```

   在国内、没有代理：

   ```bash
   node tools/setup.mjs --mirror
   ```

3. 看到"自检通过"就好了。Mac 上如果提示没有 ffmpeg，运行 `brew install ffmpeg`。

拿到的是"离线完整包"（文件夹里已经有 `node_modules`）的话，跳过第 2 步的下载，直接自检：`node tools/doctor.mjs`。

## 做第一条视频

对助手说：

> 用 boke-creator 做一条口播视频。

它会带你走五步，每一步等你点头才往下：

| 步 | 你做什么 | 大约多久 |
|---|---|---|
| 1 表达卡 | 回答几个问题：说给谁、想说哪一件事、依据是什么 | 10 分钟 |
| 2 口播稿 | 看它写的稿子，出声读一遍，改到顺口 | 10 分钟 |
| 3 录音 | 用手机照着稿子读一遍，把录音文件放进作品文件夹 | 5 分钟 |
| 4 画面 | 看它给每句话配的画面字，看 12 秒预览 | 10 分钟 |
| 5 成片 | 从头到尾看一遍成片，确认意思没被改歪 | 5 分钟 |

想先看看成品长什么样，说："先跑一遍示例。"

之后想改：直接说"第三句的画面字改成……""标题换成……""换个蓝色"。只改画面不用重录；改了要说的话才需要重录。

## 成片是什么样

- 竖屏 1080×1920，30 帧，mp4。
- 黑金风格：顶部标题和署名，中间是随说话出现的文字动画，下方是字幕。
- 四种画面：一行要点、大字金句、新旧对比、带序号的步骤清单。
- 字幕无底色、无标点，关键词换色。
- 每 3 秒内一定有画面变化。
- 强调色可以换（金、青绿、橙、蓝、粉，或任意色值）。

## 你的东西在哪

每条视频一个文件夹，里面：

```
表达卡.md     你想说什么（第 1 步的结果）
口播稿.txt    稿子，唯一需要手改的文件
录音文件      你放进来的
预览.mp4      开头 12 秒的低清预览
成片.mp4      最终的视频；上一版自动留作 成片_上一版.mp4
制作文件/     中间文件，可以删
```

录音在本机识别，不上传。技能本身不联网（安装时除外）。

## 常见问题

**一定要自己录音吗？** 建议自己录，这样才是你。也可以用配音服务生成后把音频文件放进来，做法一样；只用你本人的声音或你有权使用的音色。

**录音读错了怎么办？** 读错的那一句停一秒重读一遍，继续往下。多出来的那遍、"嗯啊"和长停顿可以自动剪掉，剪之前会把清单给你看。

**出错了怎么办？** 把报错原样告诉助手。排查表在 `references/故障处理.md`。

**能做更长的吗？** 设计目标是 60–90 秒。更长的没有充分测试过。

## 已知范围

- 在一台 Windows 11 电脑上从零安装并出片验证过。**Mac 上还没有实测**，遇到问题请反馈。
- 只有"黑金水墨"一套风格。
- 没有背景音乐、没有封面生成。
- 机器检查通过不代表片子好看，最后一定要自己看一遍。
