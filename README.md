# 播客制作人（boke-creator）

对着 AI 助手说话，把一期播客的原始录音剪成**能直接发布的精编版**：本地转写、分说话人，AI 提出编排方案（分哪几个板块、删什么、为什么删、片头放哪几句），你同意后自动剪辑、把每个人的音量调平、加配乐、统一响度，最后交付 mp3 和带时间轴的节目简介。不用剪辑软件，不用显卡，录音不离开你的电脑。

适合：已经在做播客、录完不想花一整天剪的人。单人、多人一个文件、多人多轨（每人一个话筒）都行。

## 你需要准备

- 一台 Windows 10/11 或 Mac 电脑，约 2 GB 空闲磁盘（技能约 330 MB；剪一期一小时的节目，中间文件约 1.3 GB）。
- 一个能读技能、能在电脑上运行命令的 AI 助手，见下表。
- Node.js LTS 版（18 以上）。WorkBuddy 自带，不用另装；用其他助手要自己装：[官网](https://nodejs.org)，国内打不开就用[镜像](https://npmmirror.com/mirrors/node/)。装完重开终端。
- 一期播客的原始录音（mp3、m4a、wav 都行）。

### 用哪个 AI 助手

| 助手 | 能不能用 | 不开代理 | 说明 |
|---|---|---|---|
| WorkBuddy（腾讯） | 能 | 能 | 自带 Node，用它跑自检通过；有用户在 WorkBuddy 里装好过。在 WorkBuddy 界面里完整走五步还没实测 |
| Claude Code | 能 | 不能，或改用 DeepSeek 接口（见下） | 开发和全部实测都在这里 |
| Codex | 能 | 不能 | 技能格式兼容，没在 Codex 里跑过脚本 |
| 豆包专业版（办公任务模式） | 应该能 | 能 | 它能装技能、能操作本机。需要专业版和本地授权，还没实测 |
| DeepSeek | 不能直接用 | 能 | DeepSeek 的聊天应用不能在电脑上运行命令。可以在上面的助手里换成 DeepSeek 模型来用 |

**不开代理用 Claude Code：** DeepSeek 官方支持把 Claude Code 接到 DeepSeek 模型上，[设置方法](https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/claude_code)。要在 DeepSeek 开放平台注册、充值、创建自己的 API Key，按用量付费。这条路还没实测。

## 安装

**最省事：让助手自己装。** 把下面这段话原样发给你的 AI 助手：

> 请从 https://modelscope.cn/models/jimmy444629/boke-creator-models/resolve/master/skill/boke-creator.zip 下载播客制作人技能（约 2 MB），解压到你的技能目录，解压后应该是 `技能目录/boke-creator/SKILL.md`，中间不要多套一层文件夹。然后用 boke-creator 技能帮我装好环境。

这个链接在国内不用登录、不开代理就能下载，永远指向最新版。历史版本在[魔搭仓库](https://modelscope.cn/models/jimmy444629/boke-creator-models/files)的 `skill/` 文件夹里。

**自己装：**

1. 下载上面的 zip 包，把解压出来的 `boke-creator` 文件夹放到助手的技能目录。不要从 GitHub 克隆，在国内会被限速到很慢。
   - WorkBuddy：在技能页面导入这个文件夹或 zip 包；或者直接放到 `~/.workbuddy/skills/boke-creator/`（Windows 是 `C:\Users\你的用户名\.workbuddy\skills\boke-creator\`），重启 WorkBuddy。
   - 豆包专业版：切到"办公任务"模式，在技能管理里导入；或者放到 `~/.agents/skills/boke-creator/`。以豆包当前版本的说明为准。
   - Claude Code：`~/.claude/skills/boke-creator/`（Windows 是 `C:\Users\你的用户名\.claude\skills\boke-creator\`）
   - Codex：`~/.codex/skills/boke-creator/`
   - 放好后检查一下：`boke-creator` 文件夹里直接就能看到 `SKILL.md`，中间不要多套一层文件夹。
2. 打开助手，说：

   > 用 boke-creator 技能，帮我装好环境。

   它会运行安装脚本，下载约 330 MB（识别程序、识别模型、播客用的小模型，电脑上没有 ffmpeg 时再加一份），全部放在技能文件夹里，不改系统。也可以自己在技能文件夹里运行：

   ```bash
   node tools/setup.mjs
   ```

3. 看到"自检通过"就好了。

默认全部走国内源，不开代理也能装：识别程序和 ffmpeg 来自 npmmirror，模型来自魔搭（[转存仓库](https://modelscope.cn/models/jimmy444629/boke-creator-models)），都按校验值核对。网速正常的话几分钟就装好（实测 15 秒）。某个源太慢（每秒不到 50 KB）会自动换下一个。在国外用的话加 `--official`，先走官方源。

拿到的是"离线完整包"（文件夹里已经有 `node_modules` 和 `models`）的话，跳过第 2 步的下载，直接自检：`node tools/doctor.mjs`。

## 剪一期播客

把原始录音（一个或几个音频文件）准备好，对助手说：

> 用 boke-creator 把这期播客剪成精编版，录音在 ……

它会带你走五步，每一步等你点头才往下：

| 步 | 你做什么 | 大约多久 |
|---|---|---|
| 1 素材 | 回答几个问题：节目名、几个人、录音全不全、想剪到多长。它同时在本机把整期转成文字 | 10 分钟（1 小时录音转写约 2 分钟） |
| 2 认人 | 听一段"声音点名"，告诉它每个编号是谁。可以跳过 | 5 分钟（机器分说话人要等 6–15 分钟，不用干等） |
| 3 编排 | 看它的编排方案：分哪几个板块、删了哪些、为什么。说出想留或想删的地方 | 15–30 分钟 |
| 4 声音 | 听两段 30 秒的处理前后对比，选要不要做人声处理 | 2 分钟 |
| 5 成品 | 从头到尾听一遍精编版 | 一期的时长 |

交付在节目文件夹的 `精编版/` 里：

```
精编版.mp3      统一到 -16 LUFS（可以改），有片头、板块过渡和片尾音乐
节目简介.md     标题、简介、精确到每个小话题的时间轴（可以直接贴到小宇宙）、还没确认的事
章节目录.txt    板块级时间点
主理人反馈表.md  帮别人剪的时候，连同精编版一起交给主理人
检查报告.json   响度、峰值、时长、剪口有没有吞字
```

用一期 65 分钟、十来个人的线下录音实测：剪到 40 分钟，整体音量起伏从 8.6 LU 降到 5.1 LU。

录音在本机识别和处理，不上传。技能本身不联网（安装时除外）。

## 同一档节目剪很多期：节目档案

第一次剪时，它会问你要不要给这档节目建一份**节目档案**。档案只填一次，以后每期自动用上：

- **主播和常驻嘉宾**：认过一次人之后，记住他们的声音，下一期自动认出，只剩新嘉宾要点名。
- **常错词**：节目名、人名、圈内术语，转写后自动改对。
- **片头、片尾、配乐**：用你自己的片头曲、片尾口播和音乐；也可以不要配乐。
- **响度**：默认 -16 LUFS，平台另有要求可以改。
- **剪辑偏好、简介风格**：比如"少删，闲聊也留着""开头不要钩子"，或者给几篇以前的简介让它学语气。

档案就放在节目文件夹里（`节目档案/档案.md`），你也可以自己打开改。声纹只存在你电脑上。

## 常见问题

**几个录音文件怎么办？** 它会先问你是"前后接着"录的（比如上下半场，按顺序拼起来），还是"多轨"（每人一个话筒、同时录的，对齐后混音，按音轨认人，比机器分说话人准）。

**不想认人可以吗？** 可以跳过，不影响剪辑。只是全文和简介里不会出现称呼。

**出错了怎么办？** 把报错原样告诉助手。排查表在 `references/故障处理.md`。

## 已知范围

- 在一台 Windows 11 电脑上从零安装并完整剪过。**Mac 上还没有实测**，遇到问题请反馈。
- 只用一期真实节目（65 分钟、十来个人的线下录音）完整走过一遍，编排判断还没经过主理人的反馈检验。
- 只处理音频；有视频的播客、从精编版切短视频，还没做。
- 多轨只用合成素材测过；单文件的分说话人在十来个人的场合会把同一个人拆成两个编号，要靠"声音点名"人工对上。
- 机器检查通过不代表好听，最后一定要自己从头听一遍。
