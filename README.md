# 播客制作人（boke-creator）

对着 AI 助手说话，把一期播客的原始录音剪成**能直接发布的精编版**：本地转写、分说话人，AI 提出编排方案（分哪几个板块、删什么、为什么删、片头放哪几句），你同意后自动剪辑、把每个人的音量调平、加配乐、统一响度，最后交付 mp3 和带时间轴的节目简介。不用剪辑软件，不用显卡，录音不离开你的电脑。

另一个入口：把你的一个观点做成一条 60–90 秒的竖屏口播视频（你的声音 + 全屏文字动画 + 逐字字幕）。

适合：已经在做播客、录完不想花一整天剪的人；想用短视频表达观点但不想露脸的人。

## 你需要准备

- 一台 Windows 10/11 或 Mac 电脑，约 1.5 GB 空闲磁盘。
- 一个能读技能、能在电脑上运行命令的 AI 助手，见下表。
- Node.js LTS 版（18 以上）。WorkBuddy 自带，不用另装；用其他助手要自己装：[官网](https://nodejs.org)，国内打不开就用[镜像](https://npmmirror.com/mirrors/node/)。装完重开终端。
- 做播客精编：一期播客的原始录音（mp3、m4a、wav 都行）。做口播视频：一部能录音的手机。

### 用哪个 AI 助手

| 助手 | 能不能用 | 不开代理 | 说明 |
|---|---|---|---|
| WorkBuddy（腾讯） | 能 | 能 | 自带 Node。用它自带的 Node 跑通过自检和示例预览；在 WorkBuddy 界面里完整走五步还没实测 |
| Claude Code | 能 | 不能，或改用 DeepSeek 接口（见下） | 开发和全部实测都在这里 |
| Codex | 能 | 不能 | 技能格式兼容，没在 Codex 里跑过脚本 |
| 豆包专业版（办公任务模式） | 应该能 | 能 | 它能装技能、能操作本机。需要专业版和本地授权，还没实测 |
| DeepSeek | 不能直接用 | 能 | DeepSeek 的聊天应用不能在电脑上运行命令。可以在上面的助手里换成 DeepSeek 模型来用 |

**不开代理用 Claude Code：** DeepSeek 官方支持把 Claude Code 接到 DeepSeek 模型上，[设置方法](https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/claude_code)。要在 DeepSeek 开放平台注册、充值、创建自己的 API Key，按用量付费。这条路还没实测。

## 安装

1. 把整个 `boke-creator` 文件夹放到助手的技能目录：
   - WorkBuddy：在技能页面导入这个文件夹或 zip 包；或者直接放到 `~/.workbuddy/skills/boke-creator/`（Windows 是 `C:\Users\你的用户名\.workbuddy\skills\boke-creator\`），重启 WorkBuddy。
   - 豆包专业版：切到"办公任务"模式，在技能管理里导入；或者放到 `~/.agents/skills/boke-creator/`。以豆包当前版本的说明为准。
   - Claude Code：`~/.claude/skills/boke-creator/`（Windows 是 `C:\Users\你的用户名\.claude\skills\boke-creator\`）
   - Codex：`~/.codex/skills/boke-creator/`
   - 放好后检查一下：`boke-creator` 文件夹里直接就能看到 `SKILL.md`，中间不要多套一层文件夹。
2. 打开助手，说：

   > 用 boke-creator 技能，帮我装好环境。

   它会运行安装脚本，下载约 550 MB 的东西（渲染程序、浏览器、识别模型、播客用的小模型），全部放在技能文件夹里，不改系统。也可以自己在技能文件夹里运行：

   ```bash
   node tools/setup.mjs
   ```

   在国内、没有代理：

   ```bash
   node tools/setup.mjs --mirror
   ```

3. 看到"自检通过"就好了。ffmpeg 会从国内镜像自动下载（Windows 和 Mac 都行）。

国内不开代理也能装：识别模型和播客用的小模型先从魔搭（[转存仓库](https://modelscope.cn/models/jimmy444629/boke-creator-models)）下载，ffmpeg 从 npmmirror 下载，都按校验值核对。渲染程序 OpenEdit 在国内镜像上还是旧版，会退回 npm 官方源，慢一点但一般能装上。

拿到的是"离线完整包"（文件夹里已经有 `node_modules`）的话，跳过第 2 步的下载，直接自检：`node tools/doctor.mjs`。

## 剪一期播客

把原始录音（一个或几个音频文件）准备好，对助手说：

> 用 boke-creator 把这期播客剪成精编版，录音在 ……

它会带你走五步，每一步等你点头才往下：

| 步 | 你做什么 | 大约多久 |
|---|---|---|
| 1 素材 | 回答几个问题：节目名、几个人、录音全不全、想剪到多长。它同时在本机把整期转成文字 | 10 分钟（1 小时录音转写约 2 分钟） |
| 2 认人 | 听一段"声音点名"，告诉它每个编号是谁。可以跳过 | 5 分钟（机器分说话人要等 6–15 分钟，不用干等） |
| 3 编排 | 看它的编排方案：分哪几个板块、删了哪些、为什么。说出想留或想删的地方 | 15–30 分钟 |
| 4 声音 | 听两段 30 秒的处理前后对比，选要不要做人声处理 | 2 分钟 |
| 5 成品 | 从头到尾听一遍精编版 | 一期的时长 |

交付在节目文件夹的 `精编版/` 里：

```
精编版.mp3      统一到 -16 LUFS，有片头、板块过渡和片尾音乐
节目简介.md     标题、简介、精确到每个小话题的时间轴（可以直接贴到小宇宙）、还没确认的事
章节目录.txt    板块级时间点
检查报告.json   响度、峰值、时长、剪口有没有吞字
```

用一期 65 分钟、十来个人的线下录音实测：剪到 40 分钟，整体音量起伏从 8.6 LU 降到 5.1 LU。

## 做口播视频

对助手说：

> 用 boke-creator 做一条口播视频。

它会带你走五步，每一步等你点头才往下：

| 步 | 你做什么 | 大约多久 |
|---|---|---|
| 1 表达卡 | 回答几个问题：说给谁、想说哪一件事、依据是什么 | 10 分钟 |
| 2 口播稿 | 看它写的稿子，出声读一遍，改到顺口 | 10 分钟 |
| 3 录音 | 用手机照着稿子读一遍，把录音文件放进作品文件夹 | 5 分钟 |
| 4 画面 | 看它给每句话配的画面字，看 12 秒预览 | 10 分钟 |
| 5 成片 | 从头到尾看一遍成片，确认意思没被改歪 | 5 分钟 |

想先看看成品长什么样，说："先跑一遍示例。"

之后想改：直接说"第三句的画面字改成……""标题换成……""换个蓝色"。只改画面不用重录；改了要说的话才需要重录。

## 口播视频的成片是什么样

- 竖屏 1080×1920，30 帧，mp4。
- 黑金风格：顶部标题和署名，中间是随说话出现的文字动画，下方是字幕。
- 四种画面：一行要点、大字金句、新旧对比、带序号的步骤清单。
- 字幕无底色、无标点，关键词换色。
- 每 3 秒内一定有画面变化。
- 强调色可以换（金、青绿、橙、蓝、粉，或任意色值）。

## 口播视频的东西在哪

每条视频一个文件夹，里面：

```
表达卡.md     你想说什么（第 1 步的结果）
口播稿.txt    稿子，唯一需要手改的文件
录音文件      你放进来的
预览.mp4      开头 12 秒的低清预览
成片.mp4      最终的视频；上一版自动留作 成片_上一版.mp4
制作文件/     中间文件，可以删
```

录音在本机识别，不上传。技能本身不联网（安装时除外）。

## 常见问题

**一定要自己录音吗？** 建议自己录，这样才是你。也可以用配音服务生成后把音频文件放进来，做法一样；只用你本人的声音或你有权使用的音色。

**录音读错了怎么办？** 读错的那一句停一秒重读一遍，继续往下。多出来的那遍、"嗯啊"和长停顿可以自动剪掉，剪之前会把清单给你看。

**出错了怎么办？** 把报错原样告诉助手。排查表在 `references/故障处理.md`。

**能做更长的吗？** 设计目标是 60–90 秒。更长的没有充分测试过。

## 已知范围

- 在一台 Windows 11 电脑上从零安装并出片验证过。**Mac 上还没有实测**，遇到问题请反馈。
- 播客精编只用一期真实节目（65 分钟、十来个人的线下录音）完整走过一遍，编排判断还没经过主理人的反馈检验。
- 播客精编只处理音频；有视频的播客、从精编版切短视频，还没做。
- 单人、多人一个文件、多人多轨（每人一个话筒）都支持。多轨只用合成素材测过；单文件的分说话人在十来个人的场合会把同一个人拆成两个编号，要靠"声音点名"人工对上。
- 口播视频只有"黑金水墨"一套风格，没有背景音乐和封面。
- 机器检查通过不代表好听好看，最后一定要自己听一遍、看一遍。
