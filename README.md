# 播客制作人（boke-creator）

一个装进 AI 助手的技能：把一期播客的原始录音剪成能直接发布的精编版。它在本机转写、分说话人，提出编排方案（分哪几个板块、删什么、为什么），你同意后自动剪辑、调平人声、加配乐、统一响度，交付 mp3 和带时间轴的节目简介。录音不上传，不用显卡。

单人、多人一个文件、多人多轨（每人一个话筒）都行。

## 需要什么

- Windows 10/11 或 Mac，约 2 GB 空闲磁盘（技能约 300 MB，其余是剪辑时的中间文件，剪完可以清掉）。
- Node.js 18 以上。WorkBuddy 自带，不用装；别的助手要自己装：[官网](https://nodejs.org) 或[国内镜像](https://npmmirror.com/mirrors/node/)。
- 一个能读技能、能在电脑上运行命令的 AI 助手：WorkBuddy、Claude Code 实测能用；Codex 技能格式兼容，豆包专业版（办公任务模式）应该能用，这两个都没实测。DeepSeek 聊天应用不能直接用，可以在上面的助手里换成 DeepSeek 模型。

## 安装

最省事的办法：把这句话发给 AI 助手。

> 请从 https://modelscope.cn/models/jimmy444629/boke-creator-models/resolve/master/skill/boke-creator.zip 下载播客制作人技能，解压到你的技能目录，解压后应该是 `技能目录/boke-creator/SKILL.md`。然后用 boke-creator 技能帮我装好环境。

这个链接国内不用登录、不开代理就能下，永远是最新版。历史版本在[魔搭仓库](https://modelscope.cn/models/jimmy444629/boke-creator-models/files)的 `skill/` 文件夹里。

自己装：

1. 下载上面的 zip，把 `boke-creator` 文件夹放进助手的技能目录（比如 `~/.workbuddy/skills/`、`~/.claude/skills/`、`~/.codex/skills/`）。打开后要直接看到 `SKILL.md`，中间别多套一层。
2. 在 `boke-creator` 文件夹里运行 `node tools/setup.mjs`，看到"自检通过"就好了。它会下载约 300 MB 的识别程序和模型，全放在技能文件夹里，不改系统。默认走国内源；在国外加 `--official`。
3. 拿到的是离线完整包（里面已经有 `node_modules` 和 `models`），跳过下载，直接运行 `node tools/doctor.mjs` 自检。

配乐默认用到哪首下哪首。要在没网的地方剪，先运行 `node tools/setup.mjs --music` 全部下好（约 52 MB）。

**从旧版升级：** 解压覆盖后运行一次 `node tools/setup.mjs`。它会列出旧版留下的文件再删掉，已经装好的不重新下载。想先看清单不动手，加 `--check`；自己改过旧版模板的，先这样看一眼，另存一份。

## 剪一期

对助手说"把这期播客剪一下，录音在……"。它会带你走五步，每步等你点头才往下：

**素材**（节目名、几个人、想剪多长，同时在后台转写）→ **认人**（听声音点名，可跳过）→ **编排**（看方案，说想留想删的）→ **声音**（听处理前后对比）→ **成品**（从头听一遍）。

中途关了对话也没关系，下次说"继续上次那期"。成品在这期目录的 `精编版/` 里：精编版.mp3、节目简介.md、章节目录.txt、检查报告.json，帮别人剪时还有一份交给主理人的 主理人反馈表.md。

**节目档案：** 同一档节目剪很多期时，可以建一份档案，记住主播和常驻嘉宾的声音、常错词、片头片尾和配乐、响度、剪辑偏好，以后每期自动用上。档案是普通文件，自己也能改；声纹只存在你电脑上。

## v0.7.0 更新

- 后台转写和分说话人一起跑，等分说话人跑完才结束，不会被助手中途停掉；开工、出成品各一条命令。
- 能加补录的旁白，或把两期前后拼成一期；一个录音文件里有几条音轨时会先问用哪条。
- 节目档案的声纹认人更稳：拿不准就不填，记错了能改回来。
- 听成品时直接说"12:30 那句删掉"，它会对回原话再改方案。
- 剪完可以清掉中间文件，一期一小时的节目能腾出约 0.5–1 GB；录音不再复制一份。
- 更多安全确认：方案改过要重新确认、录音换过要先重新转写、嘉宾不同意发布会停下；文件被占用、只读、录音不完整时用中文说清楚怎么办。

## 常见问题

**几个录音文件怎么办？** 它会问是"前后接着"录的（上下半场、补录，按顺序拼），还是"多轨"（每人一个话筒同时录）。

**一定要我点头才剪吗？** 是。编排方案和人声处理你没同意，它不会出成品。

**录音会复制一份吗？** 不会。同一个盘用硬链接（和原文件是同一个文件），别的盘直接读原文件。剪完前别挪，也别在原位置改（降噪后原地保存、录音软件用同名文件覆盖都算），要改就另存新文件；挪了告诉助手新位置。想要一份互不影响的拷贝，让助手开这期时加 `--copy`。

**能用 AI 配音念旁白吗？** 不能。用到的每一句都要真有人录过。

出错了把报错原样告诉助手。更多问题见 `references/故障处理.md`。

## 已知范围

- 在两台 Windows 电脑上完整剪过真实节目。**Mac 上还没实测。**
- 多轨只用合成素材测过，补录还没用真实录音测过。人多（十来个人）时，机器可能把同一个人拆成两个编号，要靠声音点名对上。
- 只处理音频。录了画面的节目，先把声音提取出来再剪。
- 机器检查通过不等于好听，最后一定要自己听一遍。
