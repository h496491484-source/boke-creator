# 故障处理

先看命令自己的输出：每个脚本停下时都会说原因和办法。下面按"看到什么"查。

## 安装

| 看到 | 原因 | 办法 |
|---|---|---|
| `node` 不是内部或外部命令 / command not found | 没装 Node | 用 WorkBuddy 的话，改用它自带的 `%USERPROFILE%\.workbuddy\binaries\node\versions\<版本>\node.exe`。其他情况到 https://nodejs.org 装 LTS 版，国内用 https://npmmirror.com/mirrors/node/ ，装完**重开终端** |
| setup 第 2 步"没装成" | npm 连不上 | 换网络或开代理再跑；国内试 `node tools/setup.mjs --mirror` |
| setup 第 3 步"固定版本的浏览器没下载下来，先用电脑上已有的" | 下载地址连不上 | 能出片，不用管。想换回固定版本，网络好的时候再跑一次 setup |
| setup 第 3 步"电脑上也没找到 Chrome 或 Edge" | 两条路都不通 | 装一个 Chrome，再跑 setup |
| setup 第 4 步模型没下载下来 | 魔搭、hf-mirror、GitHub 都没连上 | 先确认能打开 https://modelscope.cn ，再跑一次 setup；有别的国内地址可以设环境变量 `BOKE_MODEL_MIRROR=<地址>`；或者让已装好的人把 `models/sense-voice` 文件夹拷给你，然后 `node tools/get-model.mjs --dir <文件夹>`（压缩包用 `--file`）；或者直接用离线完整包 |
| ffmpeg 未通过 | 没装，或自动下载没成功 | 先 `node tools/get-ffmpeg.mjs`（从国内镜像下，Windows 和 Mac 都行）；还不行：Windows `winget install Gyan.FFmpeg`，Mac `brew install ffmpeg`，装完重开终端再跑 `node tools/doctor.mjs` |
| 示例朗读声音"提示" | 系统没有中文朗读声音 | 只影响跑示例，做自己的片子不受影响。想跑示例按提示在系统设置里加中文语音 |
| Mac 上识别程序"加载不起来" | 系统拦了下载来的动态库 | 系统设置 → 隐私与安全性里放行；或在终端运行 `xattr -dr com.apple.quarantine "<技能>/node_modules"` |

| setup 第 4 步"播客用的模型没下全" | GitHub 和镜像都连不上 | 只做口播视频可以不管。要做播客精编：让已装好的人把技能目录里的 `models/podcast` 文件夹拷给你，然后 `node tools/get-model.mjs --podcast --dir <文件夹>` |

安装可以反复跑，装好的会跳过。全部东西都在技能目录里；想彻底重装，删掉里面的 `node_modules`、`.state`、`models`、`boke-creator.local.json` 再跑 setup。

## 出片

| 看到 | 原因 | 办法 |
|---|---|---|
| 作品目录里有 N 个录音，不知道用哪个 | 放了多个音频文件 | 只留一个，或头部写 `配音：文件名` |
| 稿子和录音没对上，录音里多出来「……」 | 口头语、重复、口误 | `clean.mjs --dry` 看清单 → 本人同意 → `clean.mjs` → 本人听一遍 |
| 稿子和录音没对上，稿子里有、录音里没读到 | 漏读 | 重录，或把那句从稿子里删掉 |
| 对上率低于 80% | 拿错了稿子或录音，或录音质量太差 | 核对文件；换安静的地方重录 |
| 稿子是「1268」，音频这里是「一千二」 | 数字读法 | 头部写 `读音：1268=一千两百六十八` |
| 字幕带标点 / 字幕超过 2 行 × 15 字 | 一句太长 | 拆成两句，或在中间加 `/` |
| 关键词不在这句字幕里 | `*词*` 跨了标点，或写错字 | 让星号里的字原样落在一条字幕内 |
| 画面字有 N 个字，@X 最多 M 个字 | 画面字太长 | 改短 |
| 连着写了超过 4 条 @步骤 | 清单放不下 | 中间加 `# 小标题` 分成两组 |
| 超过 3 秒没有画面变化 | 节点不够 | `beats.mjs --plan` → 改字 → `--apply` |
| 补不了：某段时间里没有合适的位置 | 录音里有长停顿 | 先 `clean.mjs` |
| 出方案之后稿子改过了 | 方案过期 | 重新 `beats.mjs --plan` |
| 记号后面没有口播文字 | 稿子最后一行是 `@…` | 节点要写在句子前面，不能放在末尾 |
| 当前模板画不了这些记号，已跳过 | 用了不认识的 `@记号` | 只有 `@字` `@大字` `@对比` `@步骤` 四种 |
| 渲染失败 | 多半是浏览器或磁盘 | 先 `doctor.mjs`；再试 `make.mjs <作品> --full`；还不行删掉 `<作品>/制作文件` 重跑 |

## 成片检查没过

| 检查项 | 意思 | 办法 |
|---|---|---|
| 空画面 | 有一段只有背景 | 多半在开头：第一句前面加一个节点 |
| 画面静止 | 连续 3 秒画面完全不动 | 那一段补节点 |
| 静音 | 正文里有 1 秒以上没声音 | `clean.mjs` 缩短停顿，或重录 |
| 响度（未通过） | 爆音，峰值超过 0 | 录音本身爆了，离远一点重录 |
| 响度（提示） | 整体偏轻或偏响一点 | 可以不管 |
| 音画时长 | 画面和声音差 0.1 秒以上 | `make.mjs <作品> --full` |

## 看起来不对，但没报错

| 现象 | 办法 |
|---|---|
| 字幕比声音早或晚 | 多半是录音里那一句前面有杂音被当成了字。`clean.mjs` 后重出；还不对就重录那一段 |
| 剪过的录音听着有"吃字"或跳一下 | 想退回没剪的版本：删掉 `<作品>/voice.wav` 再运行 `make.mjs`，它会从原始录音文件重新转一份（当初放进来的就是 `voice.wav` 的话，把 `voice_原始.wav` 改名回 `voice.wav`）。然后重录有问题的句子，不靠剪 |
| 标题换行、第二行只剩一个字 | 标题改到 8 个字以内 |
| 颜色看不清 | 强调色太暗，换亮一点的 |
| 改了稿子，成片没变 | 确认改的是 `<作品>/口播稿.txt`；加 `--full` 强制重出 |

## 播客精编

| 看到 | 原因 | 办法 |
|---|---|---|
| 节目目录第一层没有录音文件 | 录音放进了子文件夹，或还没放 | 放到节目目录第一层，或用 `podcast/new.mjs <节目> <录音>` 拷进来 |
| transcribe：有 N 个录音文件，先写"录音方式" | 几个文件不知道是前后接着还是多轨 | 问主理人，在 节目信息.md 写"前后接着"或"多轨"；多轨再写"音轨对应" |
| 多轨：两个人的话错开了、像回声 | 某条音轨晚开始录 | 找一句两条轨里都听得到的话，量出差几秒，写进"音轨偏移"（晚开录的写 +秒数），`transcribe.mjs --force` 后重跑 speakers |
| 多轨：某个人的话被标成了别人 | 同一间屋子录、串音太大，或某人声音太小 | 在 说话人.md 和全文里核对；差得多时考虑每人一个房间录 |
| 分说话人分出了几十上百个编号 | 阈值太小 | 默认 0.9 就好；改过的话 `speakers.mjs <节目> --threshold 0.9 --force` |
| 声音点名里同一个人出现两次 | 机器把一个人拆成了两个编号 | 正常。说话人.md 两行填同一个称呼 |
| plan.mjs：第 N 句里找不到 startText / endText | 原文写得和全文不一字不差，或那半句在相邻的句子里 | 对着 全文.txt 改；常见是要改 from / to 的编号 |
| plan.mjs：记的原文……对不上（重新识别过？） | 重新转写后句子编号变了 | 按提示改编号，再加 `--refresh` |
| plan.mjs：一句只能出现一次 | 两段正文用了同一句 | 改成不重叠；片头钩子可以和正文重复 |
| build.mjs：编排方案改过之后还没检查 | 改了 编排方案.json 没跑 plan.mjs | 先跑 plan.mjs |
| check.mjs：接缝"提示"，某处可能吞了字 | 剪口离下一句太近 | 去听那个时间点。确实吞了：在编排方案里把那段的 endText 往后放几个字，或去掉 endText |
| check.mjs：响度或峰值未通过 | 很少见 | 重新 build；还不行看 `references/播客_人声处理.md` |
| 处理后人声发闷、停顿时底噪一起一伏 | 这期录音不适合降噪或调平 | 编排方案里写 `"voice": "raw"`，重新确认"声音" |

## 还是不行

把这三样发给帮你的人：`node tools/doctor.mjs` 的输出、出错那条命令的完整输出、`<作品>/口播稿.txt`。不要发录音，除非对方需要并且你愿意。
