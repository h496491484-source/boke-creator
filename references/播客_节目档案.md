# 节目档案

一档节目设置一次，以后每期自动用上。不同的主理人想要的不一样：有的有固定片头曲和片尾口播，有的不要配乐，有的要求少删，有的平台要求 -14 LUFS。这些都写在档案里，不用每期重新说。

只剪一期的不用建档案，全用默认值也能剪。

## 放在哪

```
播客精编/某某播客/            节目文件夹，一档节目一个
  节目档案/
    档案.md                   人填（主理人说，你写）
    声纹.json                 程序写（show.mjs --learn）
    素材/                     片头、片尾、配乐音频，以前的简介
  2026-11-20_第12期/          一期一个节目目录
  2026-11-27_第13期/
```

新的一期建在节目文件夹下，就会自动找到档案（从节目目录往上找三层）。不在一起时，`new.mjs ... --show <节目文件夹>`，或在 `节目信息.md` 写"节目档案：路径"。写"节目档案：无"就不用档案。

建档案：`node tools/podcast/show.mjs --new <节目文件夹> --name <节目名>`。看档案：`node tools/podcast/show.mjs <节目目录>`。

## 每一栏怎么用

| 栏目 | 谁读 | 用在哪 |
|---|---|---|
| 节目名、主持人、目标时长、发布平台 | new.mjs | 新的一期自动带进 `节目信息.md` |
| 常驻嘉宾 | show.mjs --learn | 和主持人一起，是记声纹的名单 |
| 剪辑偏好 | 你（AI） | 第 3 步编排前先读，照着做；和编排原则冲突时听主理人的 |
| 简介风格 | 你（AI） | 第 5 步写简介正文时照着写；写的是文件名就去 素材/ 读那份旧简介 |
| 片头 | build.mjs | 放在片头钩子之后、正文之前；没有钩子就放最前面。调到和人声一样响 |
| 片尾 | build.mjs | 正文结束 1 秒后播放。有片尾时，不再铺默认的片尾音乐 |
| 配乐 | build.mjs | "默认"：技能自带的 CC0 曲子；文件名：用节目自己的；"无"：不加配乐（片头片尾照放） |
| 配乐署名 | notes.mjs | 用自己的配乐时写进简介；没写会在"发布前要确认"里提醒 |
| 响度 | build.mjs、check.mjs | 默认 -16 LUFS；只接受 -24 到 -10 之间 |
| 常错词 | fulltext.mjs | 每行 `- 错的 → 对的`，转写后自动替换。字的时间、句子编号都不变 |

配乐会自动调音量：比人声目标响度低 4 dB，人声出来时再压低。

## 怎么填

和主理人聊的时候顺手记，不用一次填完：

- 第一次建：节目名、主持人、常驻嘉宾、平时剪多长、有没有固定片头片尾（有的话请他把音频发过来，放进 `素材/`）、用不用配乐、发哪些平台。
- 读全文发现节目名、人名、术语认错：问对的写法，加进常错词。
- 他对编排提的意见里，每期都适用的：问他要不要记进"剪辑偏好"。
- 他发来以前写的简介：放进 `素材/`，在"简介风格"写文件名。

改档案前跟他说一声改什么；不替他编偏好。

## 声纹

- 认人确认之后，运行 `show.mjs --learn <节目目录>`。它会把这期 `说话人.md` 里填了称呼、而且在档案"主持人""常驻嘉宾"里的人记下来。称呼写法要和档案里一致。同一个人被拆成两个编号、两行填了同一个称呼的，会合在一起记。
- 下一期运行 speakers.mjs 时，会和档案里的声纹比对：
  - 相似度 ≥ 0.75、而且明显比别人像：预填称呼。
  - 0.62–0.75：只在说话人.md 末尾写"有点像"，不填。

  这是机器猜的，主理人还是要听点名核对。
- 每多记一期，声纹会更新一次。旧的最多按 5 分钟算权重，因为换了设备或场地，声音会变。
- 一次性的嘉宾默认不记。主理人要求时加 `--all`。删掉某人：`show.mjs --forget <节目目录> <称呼>`。
- 声纹只存在本机的 `节目档案/声纹.json`。它是能认出一个人的生物特征：不上传，不发给别人；帮别人剪时，档案归主理人。

阈值是 2026-11-18 用一期 65 分钟、十来个人的线下录音定的。同一个人在前后半场之间，相似度中位数 0.89，最低 0.72（这个人前半场只说了 16 秒）；不同的人最高 0.67。录音条件差别很大的两期（比如线下换成线上）还没测过。
