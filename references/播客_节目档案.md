# 节目档案

一档节目设置一次，以后每期自动用上。不同的主理人想要的不一样：有的有固定片头曲和片尾语，有的不要配乐，有的要求少删，有的平台要求 -14 LUFS。这些都写在档案里，不用每期重新说。

只剪一期的不用建档案，全用默认值也能剪。

## 放在哪

```
播客精编/某某播客/            节目文件夹，一档节目一个
  节目档案/
    档案.md                   人填（主理人说，你写）
    声纹.json                 程序写（show.mjs --learn）
    素材/                     片头、片尾、配乐音频，以前的简介
  2026-11-20_第12期/          一期一个节目目录
  2026-11-27_第13期/
```

新的一期建在节目文件夹下，就会自动找到档案（从节目目录往上找三层；按季分子文件夹也找得到，`节目信息.md` 的"节目档案"一栏空着就行）。不在一起时，`node "<技能>/tools/podcast/new.mjs" "<节目>" "<录音文件>" --show "<节目文件夹>"`，或在 `节目信息.md` 写"节目档案：路径"。写"节目档案：无"就不用档案。写的路径失效了（节目目录挪过），程序会退回往上找，status、plan 会提醒改这一栏。

建档案：`node "<技能>/tools/podcast/show.mjs" --new "<节目文件夹>" --name "<节目名>"`（建在各期的上一层，一档节目一个文件夹；给的是一期节目的目录、上面或下面已经有档案的文件夹、下面放着几档节目名不同的节目（子文件夹里三层以内的也算，它们都会往上找到这份档案），都会拦下）。没档案时 status、new 给的建议会避开这几种情况：上一层（包括它的子文件夹）还放着别的节目，就建议给这档节目单独建个文件夹；这期节目名还没填、旁边只有另一档的几期，会把"是同一档就在上一层建、不是就单独建文件夹"两种都说；上面超过三层的地方有档案，就建议在 节目信息.md 写路径。看档案：`node "<技能>/tools/podcast/show.mjs" "<节目>"`。

## 每一栏怎么用

| 栏目 | 谁读 | 用在哪 |
|---|---|---|
| 节目名、主持人、目标时长、发布平台 | new.mjs | 新的一期自动带进 `节目信息.md` |
| 常驻嘉宾 | show.mjs --learn | 和主持人一起，是记声纹的名单 |
| 剪辑偏好 | 你（AI） | 第 3 步编排前先读，照着做；和编排原则冲突时听主理人的 |
| 简介风格 | 你（AI） | 第 5 步写简介正文时照着写；写的是文件名就去 素材/ 读那份旧简介 |
| 片头 | build.mjs | 放在片头钩子之后、正文之前；没有钩子就放最前面。调到和人声一样响。没有就空着或写"无" |
| 片尾 | build.mjs | 正文结束 1 秒后播放。有片尾时，不再铺默认的片尾音乐。没有就空着或写"无" |
| 配乐 | build.mjs | "默认"：技能自带的 CC0 曲子；文件名：用节目自己的；"无"：不加配乐（片头片尾照放） |
| 配乐署名 | notes.mjs | 用自己的配乐时写进简介；没写会在"发布前要确认"里提醒 |
| 片头片尾署名 | notes.mjs | 片头、片尾里用了别人的音乐时写进简介；都是自己的写"不用"。有片头片尾而这栏没写，会在"发布前要确认"里提醒（旧档案没有这一栏，自己加一行 `- 片头片尾署名：……`；和改档案的其他栏一样，加了以后当期精编版要重剪，最好在交付之后加） |
| 响度 | plan.mjs、build.mjs、check.mjs | 默认 -16 LUFS；只接受 -24 到 -10 之间（播客一般 -19 到 -14）。写数字，全角也认；写"默认"、"无"也行（都是 -16，和空着一样）；写了认不出数字的（"小宇宙标准"），plan 会拦下 |
| 人声处理 | build.mjs、status.mjs | 第一期听过对比后填"处理"或"不处理"（后面可以加括号说明）；以后每期照这个，第 4 步自动跳过。写了别的认不出来，status、show 会提醒。某一期想重新比，就在那期编排方案里写 voice |
| 常错词 | fulltext.mjs | 每行 `- 错的 → 对的`，转写后自动替换。字的时间、句子编号都不变 |

"无""默认""处理""不处理"这些字眼后面可以带标点、括号说明（"无。""没有（以后再加）""处理（第一期听过）"）。片头片尾找不到、读不出来或太长，响度写错，plan 就会拦下，说清楚要改的是档案，不是编排方案。

配乐会自动调音量：比人声目标响度低 4 dB，人声出来时再压低。

## 怎么填

和主理人聊的时候顺手记，不用一次填完：

- 第一次建：节目名、主持人、常驻嘉宾、平时剪多长、有没有固定片头片尾（有的话请他把音频发过来，放进 `素材/`）、用不用配乐、发哪些平台。
- 读全文发现节目名、人名、术语认错：问对的写法，加进常错词。
- 他对编排提的意见里，每期都适用的：问他要不要记进"剪辑偏好"。
- 他发来以前写的简介：放进 `素材/`，在"简介风格"写文件名。

改档案前跟他说一声改什么；不替他编偏好。

## 声纹

- 认人确认之后，运行 `node "<技能>/tools/podcast/show.mjs" --learn "<节目>"`。它会把这期 `说话人.md` 里填了称呼、而且在档案"主持人""常驻嘉宾"里的人记下来。称呼写法要和档案里一致。同一个人被拆成两个编号、两行填了同一个称呼的，会合在一起记。
  - 认人没确认（或确认后 说话人.md 又改过）不记：机器预填、主理人没核对的称呼记错了会弄脏档案。
  - 先全部检查一遍，有问题一个都不记：这期的声音和档案里记的这个人不像（< 0.62），或者两行填了同一个称呼、这两个编号的声音却不像，多半是填错了。请主理人听点名核对；确定没填错才加 `--force`。
  - 新记的称呼和档案里已有的人声音几乎一样（≥ 0.78），会提醒可能是同一个人记了两个称呼。
  - 主持人、常驻嘉宾这期都没出现：不用记，status 也不会催。
- 称呼记错了：改好 `说话人.md`、重新确认认人，再运行一次 `--learn`，会把这期记的那份换掉（声纹按期分开存，每期一份）。称呼没变就跳过，不会重复记。一期节目按"相对节目文件夹的路径"认（`第二季/第1期` 和 `第1期` 是两期），再记一个录音的指纹：目录改了名还认得出是同一期，复制出来的同一份录音不重复记。
- 下一期运行 speakers.mjs 时，会和档案里的声纹比对：
  - 相似度 ≥ 0.75、而且明显比别人像：预填称呼。档案里只记了一个人时，要 ≥ 0.78。
  - 0.62–0.75：只在说话人.md 表格上方写"有点像"，不填。
  - 几个编号都像同一个人、这几个编号彼此却不像（< 0.78）：两个都够像，或者一个够像、一个有点像而且两个差不多像（相差不到 0.15），一个都不填，写出来请主理人认。档案里这个人的声纹混进过别人的声音时，常见一个 0.82、一个 0.76，填上去的可能正好是嘉宾。够像的那个明显最像（比如主持人 1.0、某位嘉宾 0.63）不算：主持人照常预填，那位嘉宾只写"有点像"。
  - 档案里两个称呼的声纹几乎一样（同一个人记了两次）：不会互相抵消，照常认出，并提醒删掉一个。
  - 档案里有旧版（0.7 以前）记的声纹：那时的算法不一样，相似度会偏，要 ≥ 0.78 才预填；speakers、status、show 都会提醒重记：对最近一期认人确认过的节目 `--learn`，会扔掉旧版的、用这期（加上 0.7 以后记过的几期）重新记，不叠在旧的上面，不用先 `--forget`。这期的声音和档案里同名的（旧版那份或 0.7 以后记的）明显不像时，和新版档案一样停下、一个都不记（多半是这期称呼填错了），确认没填错才加 `--force`。

  这是机器猜的，主理人还是要听点名核对。
- 每多记一期，声纹会更新一次。旧的最多按 5 分钟算权重，因为换了设备或场地，声音会变。每期从这个人最长的几段里取约 60 秒（长的一段切成 15 秒一块）。
- 一次性的嘉宾默认不记。主理人要求时加 `--all`。删掉某人：`node "<技能>/tools/podcast/show.mjs" --forget "<节目>" "<称呼>"`。删掉后再跑 speakers，机器上次按声纹预填、主理人没改过的这个称呼会清空，说话人.md 里写明"这次没再认出"；主理人自己填的、改过的照旧留着。
- 单人节目转写时不分说话人，没有声纹可记，一般也用不着（只有一个人，不用认）。以后会有嘉宾、想让程序认出主持人的话：对一期运行 speakers.mjs，在 说话人.md 填主持人的称呼，确认认人，再 `--learn`。
- `--learn` 要对某一期运行；给的是节目文件夹、`节目档案/` 或不存在的目录，会说清楚。
- 声纹只存在本机的 `节目档案/声纹.json`。它是能认出一个人的生物特征：不上传，不发给别人；帮别人剪时，档案归主理人。

阈值是 2026-11-18 用一期 65 分钟、十来个人的线下录音定的。同一个人在前后半场之间，相似度中位数 0.89，最低 0.72（这个人前半场只说了 16 秒）；不同的人最高 0.67。11-22 改成长段切块、每人合计约 60 秒以后，同一期不同的人最高到 0.73，离 0.75 只差一点，所以还要"明显比别人像"、档案里只记了一个人时要 ≥ 0.78 才预填。录音条件差别很大的两期（比如线下换成线上）还没测过。
