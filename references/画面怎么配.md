# 画面怎么配

画面只有文字动画，所以"画面变化"就是画面节点的出现。规则：**任意 3 秒内必须有一次变化**（换场景或出现新节点）。两次变化之间不少于 1 秒。

## 四种节点

每个节点单独占一行，写在它要出现的那句话**前面**。一个节点一直显示到下一个节点出现。

| 记号 | 画面 | 什么时候用 | 字数 |
|---|---|---|---|
| `@字 文本` | 一行金字加下划线 | 默认。提炼这句话的要点 | 最多 9 个字一行，建议不超过 8 |
| `@大字 文本` | 更大的字，从略大缩回来 | 全片的核心观点、金句、结论、转折。一条片子 2–4 处，多了就不"大"了 | 最多 6 个字一行，上限 12 |
| `@对比 旧 \| 新` | 上面一行出现后被划掉，下面一行亮起来 | 以前和现在、误区和正解、别人怎么做和我怎么做 | 每边最多 9 个字 |
| `@步骤 文本` | 带序号的清单，一条一条累加，说过的变暗 | 第一第二第三、先后顺序、几个并列要点 | 每条最多 10 个字；一组最多 4 条 |

`@步骤` 连着写的几条算一组，序号自动编。一组中间不要插别的节点；超过 4 条就用一个 `# 小标题` 隔成两组。

`@大字` 可以加色调：`@大字 淡 文本`（米白）、`@大字 灰 文本`、`@大字 暗 文本`，用来说反面的、要否定的话。

## 从文案信号选节点

| 稿子里出现 | 用 |
|---|---|
| "只有一件事""关键是""说到底""所以" | `@大字` |
| "以前……现在……""很多人以为……其实……""不是……是……" | `@对比` |
| "第一……第二……""先……再……最后……""三个办法" | `@步骤` |
| 其他 | `@字` |

不要为了花样硬用。全片大部分节点是 `@字` 是正常的。

## 画面字怎么写

画面字不是字幕的复读。字幕已经把原话显示出来了，画面字要给的是**这段话的要点**。

| 这段话 | 不好的画面字 | 好的画面字 | 为什么 |
|---|---|---|---|
| 先想清楚说给谁听 | 先想清楚说给 | 想说给谁听 | 截断的半句话没有意思 |
| 还要讲一段亲身经历 | 还要讲一段亲身经历 | 亲身经历 | 和字幕一模一样等于没变化 |
| 我前十条视频每条讲三四个点完播率不到百分之十 | 我前十条视频 | 完播率不到 10% | 取这句话里最有分量的那个信息 |
| 说明题目还太大 | 题目的范围问题 | 讲不完就太大 | 用他的词，不换成书面语 |

规矩：

- 不超过 8 个字，不带标点，不带句首的编号。
- 只用他说过的词，或者这段话明摆着的意思。不加他没说的判断。
- 相邻两个节点不要长得太像。
- 每个场景（`# 小标题`）的第一句前面要有一个节点，否则开场只有小标题，下面是空的。

## 操作顺序

```
node "<技能>/tools/beats.mjs" "<作品>" --plan
```

程序列出要补的位置，写进 `<作品>/补节点方案.json`，稿子不动。每一项长这样：

```json
{ "n": 3, "at": 6.86, "line": 12, "where": "一句话开头",
  "covers": "一句话讲不完说明题目还太大", "show": "一句话讲不完" }
```

1. 把每一项的 `show` 改成你提炼的短语。不想补的那一处，整项删掉（但要保证 3 秒规则还过得去）。
2. 把清单念给本人：第几句配什么字。他改了就照他的改。
3. `node "<技能>/tools/beats.mjs" "<作品>" --apply`。它把 `@字` 行插进稿子，原稿另存为 `口播稿_补节点前.txt`。
4. 打开 `口播稿.txt`，把该升级的 `@字` 改成 `@大字` / `@对比` / `@步骤`，给关键词加 `*星号*`。
5. `node "<技能>/tools/make.mjs" "<作品>" --preview`。

出方案之后稿子改过了，`--apply` 会拒绝，重新 `--plan`。

几点实际会遇到的：

- 程序给的方案偏密，差不多每条字幕一个节点。两个节点说的是一回事时可以删一个，删完相邻两个节点的间隔仍要在 3 秒以内，否则 `--apply` 后会报出是哪一段超了。
- 也可以不用方案，直接在 `口播稿.txt` 里写节点行，然后运行 `make.mjs --preview`。哪里超过 3 秒它会指出来，在那一段补一行就行。稿子短、你对内容有把握时这样更快。
- `@步骤` 的每一条也受 3 秒规则管。某一步讲得久（超过 3 秒才到下一步），就把下一条 `@步骤` 提前到"第二""然后"这类词前面；最后一步讲得久，在它后面那句话前接一个 `@字`。
- `@步骤` 的节点要放在"第一""第二"这些词**前面**，不是放在内容前面，这样序号和他说"第二"是同时出现的。

程序报"补不了：某段时间里没有合适的位置"，是录音里有长停顿，先 `clean.mjs` 清理录音。

## 关键词

`*关键词*` 让字幕里的几个字换色放大。一条字幕最多一个，全片不要每条都有。选名词或数字，不选"的""很"这类虚词。关键词必须原样出现在那条字幕里。

## 强调色

头部写 `强调色：#xxxxxx`。底色是近黑色，颜色要够亮才看得清。几组可以直接用的：

| 颜色 | 值 | 气质 |
|---|---|---|
| 金（默认） | `#d9b566` | 沉稳 |
| 青绿 | `#78cdb8` | 清爽 |
| 暖橙 | `#e8955a` | 有温度 |
| 淡蓝 | `#8fb8e8` | 冷静、理性 |
| 粉 | `#e59ab0` | 柔和 |

换色后先出预览给本人看，不要直接出成片。
