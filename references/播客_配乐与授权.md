# 播客配乐与授权

## 默认配乐

技能自带一首：`template/配乐/aurora_cc0.mp3`，曲名 Aurora，作者 Trex0n。授权是 CC0（公共领域），可以商用、可以改编，不要求署名。来源和校验值见同目录的 `授权说明.md`。

`build.mjs` 把它用在三个地方，人声出现时会自动压低：

| 位置 | 时长 | 说明 |
|---|---|---|
| 片头 | 从开头到钩子结束后约 3 秒 | 先单独响约 2 秒，钩子开始后压低，钩子结束后再起来，接主持人开场时淡出 |
| 板块之间 | 约 3 秒 | 一小段过渡 |
| 片尾 | 最后一句话前 2.5 秒开始，结束后再放约 10 秒 | 最后几秒淡出 |

单独响的时候，音乐比人声轻 1–5 LU。不想要配乐，在 `编排方案.json` 里写 `"music": false`。

## 换配乐

只能用**可以免费商用**的音乐：

- 可以用：CC0、CC BY（要署名）、本人自己有授权的音乐、平台明确写着"可商用"的免费曲库。
- 不能用：流行歌、影视原声、"网上随便下的"、只写着"免费"没写授权的、CC BY-NC（不可商用）、CC BY-ND（不可改编，而剪辑和压低音量都算改编）。

换的时候：

1. 先问本人，说清楚曲子的来源和授权，本人同意再用。花钱买授权要先问，得到明确同意才做。
2. 文件放到 `template/配乐/`，按 `授权说明.md` 的格式记下曲名、作者、来源网址、授权、取得日期。
3. 把 `tools/lib/podcast.mjs` 里的 `MUSIC` 指过去。
4. 要求署名的，在节目简介的"其他"里写清楚。

## 节目里的其他声音

- 录音里现场放的歌、视频的声音，平台可能判定侵权。编排时尽量删掉，或只留几秒，并告诉主理人。
- 片头用的是参与者的原话。发布前提醒主理人跟这几位打个招呼。
