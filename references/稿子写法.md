# 稿子写法

`口播稿.txt` 是唯一手改的文件。上半部分是头部，`---` 以下是正文。`//` 开头的行是注释。

## 一份完整的例子

```text
标题：只说一件事
署名：某某的笔记
强调色：#d9b566
读音：10条=十条
---
# 先定一个观点
@大字 只说一件事
一条短视频只说一件事。
@字 想说给谁听
先想清楚*说给谁听*，
再用*一句话*把观点讲完。

# 最后留一个动作
@步骤 结尾留一个动作
结尾留一个*小动作*，
@步骤 今天就能做
让人今天就能做。
```

## 头部

| 写法 | 意思 | 要求 |
|---|---|---|
| `标题：` | 画面顶部一直显示的大标题 | 不超过 8 个字，超了会换行 |
| `署名：` | 标题上方的小字 | 名字或账号名 |
| `强调色：#d9b566` | 关键词和画面字的颜色 | 可省，默认金色。深色底上要够亮 |
| `读音：屏幕字=读法` | 字幕显示左边，录音里读的是右边 | 多个用逗号隔开 |
| `配音：文件名` | 用哪个音频 | 可省。作品目录里只有一个录音时不用写 |

## 正文

| 写法 | 意思 |
|---|---|
| 一句话一行，句末带标点 | 字幕按 `，。！？；：` 切开，一个标点一条字幕；顿号不切 |
| 空一行 | 分段 |
| `# 小标题`（单独一行） | 换一个场景，小标题显示在画面上。一条片子 2–4 个 |
| `*关键词*` | 字幕里这几个字换色放大。一条字幕最多一个 |
| `/` | 在这里强行把字幕切开（一句太长又没有标点时用） |
| `@字 文本` 等（单独一行） | 画面节点：下一个字开口时，画面出现这行字。见 `画面怎么配.md` |
| `【文本】`（写在句子里） | 说到这里时画面出现大字，等于在这几个字前面写一行 `@大字` |

屏幕上不显示任何标点。引号、括号、书名号写了也不会显示。

## 长度

- 全片 60–90 秒，大约 280–430 个字（自己念大约每秒 4–5 个字）。
- 一条字幕最多 30 个字（两行，每行 15 个）。超了会报错，拆成两句或加一个 `/`。
- 好读的字幕在 8–16 个字。

## 读音什么时候要写

稿子要和录音一个字一个字对得上。阿拉伯数字逐位读时不用管（`2` 对"二"），其余情况写明：

| 稿子里写 | 录音里读 | 头部写 |
|---|---|---|
| 1268段 | 一千两百六十八段 | `读音：1268段=一千两百六十八段` |
| 30% | 百分之三十 | `读音：30%=百分之三十` |
| AI | 诶爱 | 一般不用写，识别得出来；对不上再写 |
| 10期 | 十期 | `读音：10期=十期` |

画面节点不要正好放在改了读法的字前面，放到句首。

## 写口语，不写文章

- 短句。一口气读不完的句子拆开。
- 用他平时说话的词。"进行优化"改成"改一改"，除非他本来就这么说。
- 开头第一句就是观点或者钩子，不要"大家好我是某某"。
- 结尾留一个动作，不加"点赞关注评论区见"，除非他自己要。
- 不堆排比，不写"不是……而是……"的套话，除非那正是他的意思。

## 改稿之后

改完直接重新运行 `make.mjs`。只改了记号、关键词、小标题、标题：不用重录。改了口播的字：要重录。
